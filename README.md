# My Workout V2
Mobile-first workout tracker.

Features:
- Weekly dumbbell/bodyweight routine with Tue/Fri rest
- Set-by-set weight and rep logging
- Exercise completion
- Automatic PR recording
- Previous PR target shown under exercises
- Add/remove/reorder exercises
- Exercise tutorial search
- Rest timer
- Workout history and streak
- Progress dashboard
- PWA manifest/install support
- LocalStorage persistence

Open index.html or serve the folder from a web server for PWA installation.


### Video tutorials
The tutorial button now uses a normal YouTube search link rather than a JavaScript popup, which works better when opening the app from a local HTML file on Android.
