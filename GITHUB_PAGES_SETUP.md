# My Workout — GitHub Pages

1. Create a free GitHub repository, e.g. `my-workout`.
2. Upload every file in this folder to the repository root.
3. GitHub → **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the generated `https://YOUR-USERNAME.github.io/my-workout/` address in Chrome on Android.
7. Chrome should offer **Install app** / **Add to Home screen**.

Do NOT open `index.html` directly from the ZIP if you want PWA installation. GitHub Pages serves it over HTTPS.

Your workout data remains stored locally in the browser/device.
